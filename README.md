# 퍼프 (Puff)

같은 시간에 일하는 사람들이 작은 퍼프가 되어 Mac 화면 위를 떠다니는 앱입니다.

**[Puff 0.2.0 다운로드 — Apple Silicon](https://github.com/gkdms0910/puff-releases/releases/download/v0.2.0/Puff-0.2.0.dmg)** · [변경 사항과 체크섬](https://github.com/gkdms0910/puff-releases/releases/tag/v0.2.0)

## 설치

- Apple Silicon Mac(M1 이상), macOS 14 이상이 필요합니다. Intel Mac용 빌드는 제공하지 않습니다.
- DMG를 열고 `Puff.app`을 `Applications` 폴더로 옮깁니다.
- 현재 파일은 **Apple 공증이 없는 공개 테스트 빌드**입니다. macOS가 처음 실행을 차단할 수 있습니다. 보안 경고 없이 설치되는 정식 서명 배포본은 아직 준비되지 않았습니다.

## 사용하기

- 내 퍼프의 이름·색·장식을 고를 수 있습니다.
- 다른 퍼프를 클릭하면 이름과 하는 일을 보고 손을 흔들 수 있습니다.
- ‘나’ 표시가 있는 퍼프를 클릭해 메시지를 적고 Enter로 보내세요. 메시지는 현재 친구 방에만 표시됩니다. 최대 80자, 8초 동안 표시되며 Esc로 입력창을 닫을 수 있습니다.
- 메뉴바 → 설정 → 퍼프 투명도에서 0~80%를 조절할 수 있습니다.

## 공개 범위와 테스트 제한

- 실행하면 광장에 접속하며 이름·하는 일·외형·접속 상태가 다른 이용자에게 보입니다. 직접 입력한 메시지는 현재 친구 방으로만 전송합니다.
- 앱은 대화 기록을 저장하지 않습니다. 방 목록과 방 이름은 서버에 저장합니다.
- 메시지 발신자 신원을 서버가 보증하는 기능은 아직 없으므로, 신뢰하는 친구들과의 테스트용으로 사용해 주세요.
- 두 Mac 사이의 실제 메시지 전달은 아직 검증되지 않았습니다. 자동 업데이트도 아직 지원하지 않습니다.

이 저장소는 설치 파일과 배포 안내를 위한 공간입니다. 앱 소스 코드는 포함하지 않습니다.
